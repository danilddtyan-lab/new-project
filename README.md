# Велобюро

GitHub Pages публикует статический сайт. Новости, сборки, маршрут дня и реестр фотографий находятся в `data/`.

## Локальный запуск на Python

Требуется Python 3.10 или новее. Сторонние зависимости не нужны.

```sh
python3 backend.py --check
python3 backend.py
```

Сайт открывается на `http://127.0.0.1:8000/`. При необходимости укажите `--port 8080`.

- `GET /api/health` возвращает состояние сервера.
- `GET /api/news` принимает `category`, `region`, `q` (поиск по заголовку), `offset` и `limit` от 1 до 100. Ответ содержит записи, общее число совпадений и параметры страницы.
- `--check` проверяет схему и порядок новостей, конфиги главной и наличие и размер подтверждённых файлов изображений.

Python-сервер обслуживает локальный предпросмотр и API. На GitHub Pages страницы читают те же JSON напрямую.

## Данные

- `news.json` содержит архив новостей и карточки карусели.
- `builds.json` содержит цены, курс, комплектации и характеристики Tideace.
- `routes.json` содержит варианты маршрута дня. Ротация рассчитывается по календарю Бишкека.
- `product-media.json` содержит кандидатов и разрешённые фотографии. Для публикации положите подтверждённый WebP или JPG в `data/images/`, укажите локальный путь, источник и лицензию, затем установите `verified: true`. Используйте снимок точной модели размером от 1080 px по короткой стороне и до 300 КБ.

Пример запроса к API с фильтрацией:

```sh
curl -G 'http://127.0.0.1:8000/api/news' \
  --data-urlencode 'region=Кыргызстан' \
  --data-urlencode 'q=Seven Rivers' \
  --data 'limit=10'
```
